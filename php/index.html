📋 Setup Steps

  1. Install XAMPP - Download from apachefriends.org
  2. Start Services - Apache + MySQL in XAMPP Control Panel
  3. Create Database - Run in phpMyAdmin:
    CREATE DATABASE literary_escape CHARACTER SET utf8mb4;
  4. Run Setup - Double-click setup.bat or run php setup.php
  5. Test - Visit the test page above
▶️ Run Setup Now

🌐 Available Endpoints

Public

  • GET /api/books - Get all books
  • GET /api/books/:id - Get book by ID
  • POST /api/register - Register user
  • POST /api/login - User login
  • POST /api/admin/login - Admin login

Protected (Auth Required)

  • GET /api/cart - Get cart items
  • GET /api/favorites - Get favorites
  • GET /api/orders - Get orders
  • GET /api/user/profile - Get profile

Admin (Admin Auth Required)

  • GET /api/admin/books - Manage books
  • GET /api/admin/users - Manage users
  • GET /api/admin/orders - Manage orders
  • GET /api/admin/dashboard/stats - Statistics

💡 Tips

  • Both Node.js and PHP backends can run together
  • Use the comparison page to test both
  • PHP uses port 80, Node.js uses port 3000
  • Check test.php for detailed diagnostics
  • Enable error display in config.php for debugging
